# System Capacity & Care Load Analytics for Unaccompanied Children

## Objective

This project analyzes the system capacity and care load of
unaccompanied children using CBP and HHS data.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key KPIs

- Average CBP Custody: 171.49
- Average HHS Care: 6061.28
- Average Total System Load: 6232.77
- Maximum Total System Load: 11762
- Minimum Total System Load: 2002
- Average Net Intake: -208.55
- Prolonged Strain Days: 429
- Prolonged Strain Percentage: 59.58%

## Conclusion

The analysis shows that HHS Care represents the major portion
of the overall system load. The system also experienced
considerable variation in load, with prolonged strain observed
on 59.58% of analysed days.# system-capacity-care-load-analytics
